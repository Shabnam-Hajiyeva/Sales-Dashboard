# Beverage Sales Dashboard (Power BI)

A simple **Sales Dashboard built in Power BI** using Excel data.  
This project examines **revenue and units sold** across retailers, beverage brands, regions, and time periods.

By **Shebnem Hajiyeva**  
Computer Programming Student, Humber Polytechnic

---

## Overview
The goal of this project is to visualize sales data, making it easy to understand trends, top-performing brands, and regional performance.

---

## Data
The dataset includes:
- Retailer & Retailer ID  
- Date & Month  
- Region & State  
- Beverage Brand  
- Price per Unit  
- Units Sold  
- Revenue  

---

## Dashboard
The dashboard shows:
- Total Revenue and Units Sold  
- Monthly sales trends  
- Sales by Beverage Brand and Retailer  
- Sales by Region and State  
- Interactive filters  

---

## Tools
- Power BI  
- Microsoft Excel  

---

## How to Use
1. Download the `.pbix` file  
2. Open it in **Power BI Desktop**  
3. Use filters to explore the data
